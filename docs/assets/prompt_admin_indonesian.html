Prompt Implementasi Admin Bab I: Pendahuluan

Konteks & Aturan Umum

Dokumen ini menggabungkan seluruh rancangan modul sistem Admin MedSign AI menjadi satu instruksi YAML terstruktur yang dapat disuapkan langsung ke asisten pemrograman AI.

Kewenangan & Aturan Lintas Modul
  • Otentikasi & RBAC: Seluruh rute administratif di bawah path /admin/* wajib melewati proteksi middleware otentikasi role "admin" atau "super_admin".
  • Audit Logging: Setiap aksi sensitif yang memodifikasi database (seperti registrasi pasien, rollback augmentasi, penghapusan, dll.) wajib direkam di tabel audit_logs yang bersifat append-only.
  • Soft Delete: Seluruh tabel utama menggunakan metode soft delete (is_active / status) dan melarang hard delete demi menjaga keutuhan rekam medis.
  • Validasi File: File gambar yang diunggah (cover artikel, logo mitra, dll.) wajib divalidasi ukuran maksimal (10MB) dan tipenya di sisi backend.

Modul 1 s.d Modul 3: Manajemen Akun

Modul 1 — Kelola Pasien

Mengelola registrasi pasien tuli menggunakan NIK yang dienkripsi secara asinkron di database Supabase:

  • POST /admin/patients: Registrasi pasien, generate password acak awal, return sekali di response.
  • GET /admin/patients: List dengan pagination + search. NIK wajib ditampilkan secara bermasking (contoh: 327101********1234).
  • POST /admin/patients/{id}/reset-password: Reset password, kembalikan password baru sekali saja.
Modul 2 — Kelola Dokter

Mengelola data dokter yang bertugas di faskes (spesialisasi, lisensi medis, dll.). Endpoint CRUD mirip dengan Modul 1.

Modul 3 — Kelola Relasi Dokter-Pasien

Mengatur penugasan pasien di bawah naungan dokter pemeriksa agar lolos validasi RLS database:

  • POST /admin/doctor-patient-assignment: Daftarkan relasi penugasan baru.
  • DELETE /admin/doctor-patient-assignment/{id}: Hapus relasi penugasan dokter-pasien.

Modul 4 s.d Modul 5: Augmentasi & Motion

Modul 4 — AI Dataset Augmentation

Melipatgandakan data landmark latih secara spasial/temporal untuk menyeimbangkan kelas:

  • Menghasilkan dataset augmentasi terisolasi per run (tabel: augmentation_runs).
  • Rollback per Run: Hapus berkas hasil augmentasi dengan ID run terkait tanpa menyentuh data asli.
  • Restore / Regenerate: Hasilkan ulang data dengan random_seed yang sama.
Modul 5 — Motion Graphics 3D Visualizer

Mengekspor video visualisasi 3D dari koordinat gerak landmark tangan untuk kebutuhan HAKI:

  • Merekam checksum SHA-256 berkas video hasil ekspor.
  • Verifikasi Integritas: Pencocokan berkas di server dengan nilai checksum untuk mendeteksi perubahan ilegal.
  • Pilihan durasi ekspor real-time: 10s, 30s, 45s, 1m, 2m.

Modul 6 — Kelola Artikel

Pengelolaan blog artikel landing page. Endpoint CRUD dengan tombol publikasi yang otomatis mengisi published_at.

Modul 7 — Kelola Instagram

Prompt Implementasi Admin Bab V: Prompt YAML

Prompt YAML Siap Salin

Kamu membantu membangun panel Admin lengkap untuk MedSign, platform BISINDO medis.
Scope: Bangun HANYA panel Admin. Hubungkan ke database Supabase PostgreSQL.
Aturan Lintas Modul:
1. Validasi RBAC admin/super_admin di /admin/*
2. Tulis log audit ke tabel audit_logs untuk setiap aksi modifikasi.
3. Batasi upload file maksimal 10MB tipe gambar di backend.
4. Terapkan soft delete dan pagination.
Urutan Modul:
- Modul 1: Kelola Pasien (nik encrypted & masking, reset password)
- Modul 2: Kelola Dokter (CRUD & reset password)
- Modul 3: Kelola Relasi Dokter-Pasien (doctor_patient)
- Modul 4: AI Augmentation (isolation per run, rollback, restore)
- Modul 5: Motion Graphics (SHA-256 checksum, 5 durasi HAKI, video 3D)
- Modul 6: Kelola Artikel (Rich text, cover, slug auto-generate, publish time)
- Modul 7: Kelola Instagram (URL post, thumbnail, drag-and-drop reorder)
- Modul 8: Kelola Mitra (Upload logo, nama, kategori, reorder)
