Latar Belakang & Peran Sistem

Komunikasi yang efektif di rumah sakit merupakan kebutuhan vital. Bagi pasien tuli atau tuna rungu, kendala komunikasi dapat memicu misdiagnosis. MedSign AI hadir untuk menerjemahkan gerakan isyarat BISINDO medis menjadi teks klinis secara real-time.

Peran Pengguna & Hak Akses

Sistem ini dirancang menggunakan sistem akses berbasis peran (RBAC) yang terintegrasi penuh:

Peran Pengguna Utama Kewenangan Utama
Super Admin Staf IT Faskes Pusat Mengelola data Faskes, Admin Faskes Lokal, database backups, audit log sistem, ML model global, dan konten homepage.
Admin Perekam Medis / Staf Faskes Registrasi pasien, manajemen data dokter, penugasan dokter-pasien, rekam dataset, augmentasi data, dan training model.
Dokter Tenaga Medis / Pemeriksa Pencarian pasien, memulai sesi konsultasi, preset respon cepat, speech-to-text, menulis catatan SOAP rekam medis (RME).

Fitur Keamanan & Konten Global

1. Manajemen Faskes & Admin Lokal

Super Admin berwenang mengelola entitas Rumah Sakit/Klinik beserta akun Admin yang bertugas:

  • Klik menu Kelola Faskes pada sidebar, isi data kode faskes, nama, alamat, dan simpan.
  • Klik menu Kelola Admin Faskes untuk menugaskan staf admin lokal di RS terkait.
2. Sistem Audit Logs & Database Backups

Untuk memantau integritas data rekam medis elektronik (RME):

  • Gunakan menu Sistem Audit Logs untuk melihat siapa saja dokter yang membuka data pasien tuli. Ekspor data ke CSV untuk verifikasi kepatuhan hukum.
  • Gunakan menu Database Backups untuk memicu pencadangan asinkron. Klik *Restore* hanya jika database Supabase mengalami gangguan.
3. Kelola Konten Homepage (Modul Tentang Kami)

Konten landing page dikelola dari satu pintu untuk menjamin efisiensi:

  • Klik menu Kelola Konten, pilih tab Tentang Kami untuk menambahkan dokumentasi tim.
  • Unggah gambar menggunakan tombol **Upload Foto** (Token otentikasi Supabase sudah terintegrasi secara otomatis).

Manajemen Akun & Penugasan Medis

1. Registrasi Pasien & Reset Password

Untuk menghindari kebocoran data NIK, pasien tuli tidak bisa mendaftar sendiri. Registrasi dilakukan oleh Admin:

  1. Klik menu Kelola Pasien di Portal Admin, masukkan NIK, Nama Lengkap, dan Tanggal Lahir. NIK akan dienkripsi di database Supabase (*at-rest*).
  2. Jika pasien lupa password, gunakan tombol **Reset Password** pada baris pasien untuk menghasilkan password acak sementara.
2. Pendaftaran Akun Dokter & Penugasan Pasien

Agar dokter dapat mengakses data medis pasien sesuai kebijakan isolasi data RLS:

  1. Pilih menu Kelola Dokter, masukkan nama, spesialisasi, dan nomor lisensi medis.
  2. Pilih menu Penugasan Dokter-Pasien, tentukan nama dokter lalu centang daftar pasien yang menjadi tanggung jawabnya. Klik **Simpan Relasi**.

Perekaman Dataset & Augmentasi AI

1. Ambil Data Landmark Tangan

Melakukan perekaman sampel isyarat baru untuk menambah kapasitas latih model:

  1. Buka tab Rekam Dataset, pilih nama responden (signer), target kata, dan jumlah iterasi (minimum 5 take).
  2. Aktifkan kamera, posisikan tangan hingga MediaPipe mendeteksi lingkaran 3D hijau. Lakukan gerakan saat hitungan mundur selesai.
2. AI Dataset Augmentation & Rollback

Mengatasi ketimpangan data (data imbalance) secara cerdas menggunakan visual augmentasi:

  • Buka tab AI Augmentation, pilih kata dan atur variasi (spasial/temporal) yang ingin dihasilkan.
  • Klik **Jalankan Augmentasi** untuk memicu penambahan sampel di server.
  • Jika performa model menurun setelah augmentasi, gunakan tombol **Rollback** untuk mengembalikan dataset ke kondisi orisinal.

Balance Checker & Pelatihan Model

1. Pemantauan Dataset & Hapus Masal

Kosakata klinis harus seimbang agar model tidak bias terhadap gerakan tertentu:

  • Buka tab Balance Checker. Kata yang kekurangan data akan ditandai *NEED MORE DATA*.
  • Klik **Check Dataset** untuk membuka daftar file `.npy`.
  • Centang baris sampel yang rusak/kosong, lalu klik tombol merah **Hapus Terpilih** untuk menghapusnya secara masal.
2. Pelatihan Model Klinis Asinkron

Melatih ulang model untuk memperbarui akurasi translasi di faskes:

  1. Buka tab Training Model, tentukan arsitektur neural network (contoh: **gru**) dan epoch (default 120).
  2. Klik **Mulai Pelatihan**. Sistem akan melatih model secara asinkron di latar belakang.
  3. Server akan mendeteksi model baru dan melakukan *Auto-Reload* tanpa perlu mematikan website.

Layar Diagnosis & AI SOAP Writer

1. Mulai Sesi Konsultasi Real-Time

Menjalankan komunikasi langsung dua arah dengan pasien tuli:

  1. Pencarian pasien: Masukkan nama/RM pasien pada dashboard dokter.
  2. Klik **Mulai Sesi Konsultasi** (Tombol kontras biru indigo).
  3. Kamera pasien akan mendeteksi isyarat BISINDO dan menampilkan teks terjemahannya di layar Anda.
2. AI SOAP Writer (Notetaker Otomatis) & Rekam Medis

Mencatat rekam medis elektronik secara otomatis tanpa mengetik:

  • Setelah sesi selesai, klik tombol **Buat SOAP Note**.
  • AI Notetaker (Google Gemini) akan memproses pesan percakapan dan membuat draf SOAP (Subjective, Objective, Assessment, Plan) secara terstruktur.
  • Jika koneksi terganggu, sistem akan masuk ke **Fallback Mode** (menggunakan algoritma lokal) agar penulisan SOAP tetap berjalan.
  • Sunting bagian yang kurang tepat, lalu klik **Simpan Rekam Medis** ke database Supabase.

Pertanyaan Umum & Istilah

Pertanyaan Umum (FAQ)

Q: Mengapa tangan saya tidak terdeteksi oleh kamera?
A: MedSign menggunakan model MediaPipe Hands tingkat tinggi (complexity: 1) untuk akurasi sendi jari. Pastikan posisi tangan masuk di dalam kotak target pemindai.

Q: Mengapa ringkasan SOAP AI gagal dibuat?
A: Periksa koneksi internet atau kunci API Gemini di file `.env`. Sistem akan otomatis mengaktifkan *Fallback Mode* jika kunci API bermasalah.

Q: Berapa lama batas sesi login saya tetap tersimpan?
A: Sesi login dibatasi 2 jam demi privasi medis. Setelah 2 jam tidak aktif, sistem otomatis melakukan logout demi keamanan data.

Glosarium
  • Landmark Tangan: 21 titik koordinat sendi jari tangan yang diekstrak oleh MediaPipe.
  • TFLite Model: Berkas kecerdasan buatan terkompresi hasil pelatihan untuk mendeteksi gerakan BISINDO.
  • SOAP Note: Format penulisan catatan medis (Subjective, Objective, Assessment, Plan) standar rumah sakit.
